# `To be` для местоположения предметов

## Формула

`subject + am / is / are + place`

## Что здесь осваивается

- `to be` связывает предмет с местом;
- `is` используется с одним предметом;
- `are` используется с несколькими предметами;
- после `to be` может стоять сочетание с предлогом места.

## Примеры

- `The book is on the table.`
- `The keys are in the box.`
- `The phone is near the lamp.`
