# Сравнительная степень прилагательных

## Формула

`adjective + -er`

`more + adjective`

## Что здесь осваивается

- короткие прилагательные часто получают `-er`;
- при написании могут быть изменения: `wide -> wider`, `heavy -> heavier`, `hot -> hotter`;
- длинные прилагательные часто используют `more`;
- для сравнения двух предметов используется `than`.

## Примеры

- `long -> longer`
- `heavy -> heavier`
- `hot -> hotter`
- `beautiful -> more beautiful`
- `This table is longer than that table.`
