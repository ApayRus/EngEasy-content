# 7. Это врач. То покупатель.

## Указательные слова {new|demonstrative}

это, этот
то, тот

## Существительные {new|noun}

врач
водитель
работник
покупатель
продавец
менеджер
посетитель

## Сокращённая форма {new|contraction}

то есть

## Шаблоны с this/that {new}

это есть?
то есть?
это не есть

этот врач есть
тот покупатель есть
